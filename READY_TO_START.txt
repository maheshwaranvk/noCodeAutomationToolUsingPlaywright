🔍 TROUBLESHOOTING:

Blank Frontend Page?
→ Check browser console (F12)
→ Verify frontend/public/app.js exists
→ Restart http-server

Cannot Connect to Backend?
→ Run: curl http://localhost:3001/health
→ Check backend logs for errors
→ Verify port 3001 is available

No Screenshots/Video?
→ Check ./artifacts/ directory exists
→ Verify Playwright installed: npm ls playwright
→ Check backend logs for recorder setup

Port Already in Use?
→ Change PORT=3001 in .env (backend)
→ Modify start script in frontend/package.json for port 3000
